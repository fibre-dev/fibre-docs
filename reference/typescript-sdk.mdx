## Sandbox

A sandbox: an isolated Linux machine for code you do not want on your own. Create one, run commands in it, move files in and out, and delete it when you are done. When nobody uses it, it sleeps with its memory and comes back on the next call: every method works the same whether it is awake or asleep.

## Command

A command running in a sandbox, started with `sandbox.spawn()` or found again with `sandbox.command(id)`. Follow its output with `output()`, wait for it with `wait()`, write to it, or stop it. A kept command (`keep: true`) runs on its own: its status is `detached` and its output goes to the file named in `log`.

## errors

Every error is a `FibreError` with `status`, `code`, `requestId`, `docsUrl` and the whole answer as `body`; catch a subclass for the kind you handle. The codes are listed in [errors](/reference/errors).

| error | when |
|---|---|
| `FibreError` |  |
| `ValidationError` | The request was malformed or failed validation (400). `body.details` says which fields. |
| `AuthenticationError` | No API key, or one that is not valid (401). |
| `PaymentRequiredError` | The account's plan or balance does not allow this (402). |
| `PermissionDeniedError` | The key may not do this (403). |
| `NotFoundError` | No such sandbox, command, file or template (404). |
| `ConflictError` | The request conflicts with the current state (409), e.g. a need the chosen runtime cannot meet. |
| `RateLimitError` | Too many requests, or a limit of the plan reached (429). `retryAfter` is in seconds when the API says. |
| `ServerError` | The platform could not do it right now (5xx), e.g. no capacity to start a sandbox. Retrying later may work. |
| `ConnectionError` | The API could not be reached. |
| `TimeoutError` | A request, or a command run with a timeout, took longer than allowed. |
